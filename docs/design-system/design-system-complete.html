Panduan Penggunaan

✅ Do's

  • • Gunakan palet warna yang telah ditentukan untuk konsistensi
  • • Pastikan kontras warna memenuhi standar WCAG
  • • Gunakan animasi secara bijak untuk meningkatkan UX
  • • Test desain di berbagai ukuran layar
  • • Gunakan semantic HTML untuk aksesibilitas
  • • Optimalkan performa dengan CSS yang efisien

❌ Don'ts

  • • Jangan gunakan warna di luar palet yang ditentukan
  • • Hindari animasi yang berlebihan atau mengganggu
  • • Jabaikan aksesibilitas untuk kecepatan development
  • • Jangan hardcode warna dalam kode
  • • Hindari penggunaan !important dalam CSS
  • • Jangan lupakan testing di berbagai browser

💡 Tips Performa

Untuk mendukung 5000+ pengguna aktif, gunakan CSS yang efisien, minimalkan animasi berat, dan implementasikan lazy loading untuk gambar dan konten yang tidak langsung terlihat.
