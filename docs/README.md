# Dokumentasi Proyek TKA

Folder `docs/` sudah dipecah agar lebih mudah dinavigasi.

## Kategori

- `architecture/`
  - Dokumen arsitektur sistem dan data model.
- `design-system/`
  - Panduan dan prototipe design system.
- `planning/`
  - Task list dan perencanaan pengembangan.
- `reports/`
  - Laporan analisis, whitepaper, dan kajian.
- `specifications/`
  - Spesifikasi teknis dan paket referensi API.
- `wireframes/`
  - Kumpulan wireframe UI lintas peran.
- `archive/`
  - Berkas lama/non-prioritas yang tetap disimpan.

## Catatan

- Paket spesifikasi autentikasi lama dipindah ke:
  - `specifications/authentication-module-v1/`
- Whitepaper dikelompokkan ke:
  - `reports/whitepaper/`
