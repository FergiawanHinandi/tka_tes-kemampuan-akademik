Aplikasi Siswa

Client Siswa App

Digunakan oleh siswa untuk mengerjakan ujian di komputer atau laptop.

Versi terbaru: v2.3.1

Update terakhir: 10 Februari 2024

Informasi Teknis

System Requirements

  • OS: Windows 10 64-bit atau Linux Ubuntu 20.04
  • RAM: Minimal 4 GB (disarankan 8 GB)
  • CPU: Dual-core 2.0 GHz atau lebih
  • Jaringan: LAN 100 Mbps stabil

Panduan Instalasi

  • Panduan Instalasi Proktor Exam App

    Langkah-langkah instalasi di laboratorium komputer sekolah.

  • Panduan Instalasi Client Siswa App

    Instalasi di komputer siswa dan pengaturan awal.

  • Panduan Jaringan LAN Ujian

    Konfigurasi jaringan lokal untuk pelaksanaan ujian.

Catatan Rilis Terbaru

  • v2.3.1 - Stabilitas Ujian Massal

    • Optimasi koneksi untuk 5.000+ pengguna simultan di jaringan lokal.
    • Perbaikan auto-reconnect Client Siswa saat jaringan terputus sementara.
    • Peningkatan keamanan komunikasi antara Proktor dan Server Ujian.

  • v2.3.0 - Fitur Monitoring

    • Tampilan real-time status siswa (Online, Sedang Ujian, Selesai).
    • Fitur force submit dan pause/resume ujian per ruang.
